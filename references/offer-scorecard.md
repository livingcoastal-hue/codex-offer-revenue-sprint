# Offer Scorecard

Score each category 1-5. Give a short reason and a concrete fix.

| Category | Weight |
| --- | ---: |
| ICP clarity | 15% |
| Pain/desire intensity | 15% |
| Promise clarity | 15% |
| Differentiation | 10% |
| Proof | 15% |
| Offer stack | 10% |
| Friction and risk reversal | 10% |
| CTA and next step | 10% |

Decision guide:
- `Ready to scale`: weighted score >= 4.2.
- `Fix before traffic`: 3.2-4.1.
- `Rebuild offer`: below 3.2 or unclear buyer/problem.
- `Needs inputs`: not enough copy, audience, or offer detail.

## Minimum Intake

- Target customer.
- Offer name and outcome.
- Price or price range.
- Sales channel.
- Current page, email, ad, or pitch.
- Main conversion problem.
- Proof assets.
- Primary CTA.

## Common Revenue Leaks

- Headline names the product, not the buyer outcome.
- Audience is too broad.
- Promise lacks a measurable transformation.
- No clear mechanism for why the offer works.
- Proof is buried or generic.
- CTA asks for too much too soon.
- Pricing is shown without value framing.
- Page has features but no pain, stakes, or proof.
- Follow-up stops after one touch.
