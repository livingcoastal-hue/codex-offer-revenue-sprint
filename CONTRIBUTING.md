# Contributing

Keep this skill practical, ethical, and focused on revenue work people can actually execute.

## Guidelines

- Keep `SKILL.md` concise.
- Put detailed marketing frameworks in `references/`.
- Put reusable output formats in `assets/templates/`.
- Include exact rewrites and next actions, not just advice.
- Do not add manipulative tactics, false scarcity, fake claims, or unverifiable proof.

## Validation

Before publishing changes, check that:

- `SKILL.md` has YAML frontmatter with only `name` and `description`.
- The skill name is lowercase hyphen-case.
- The description explains both what the skill does and when to use it.
- Templates are plain Markdown and easy to reuse.
